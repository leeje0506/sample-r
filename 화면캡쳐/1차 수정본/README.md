# 리라즈의 공연 준비 대작전 — 1차 수정본 기록

기록일: 2026-09-23  
기준 커밋: `0f4a2f4`  
캡처 규격: 모바일 390 × 844 CSS px (2배 해상도 PNG)

## 1. 버전 정의

기존의 단순 질문형 픽셀 룸을 팬 이벤트 준비 게임으로 확장한 첫 번째 통합 버전이다. 여섯 캐릭터의 방을 순서대로 방문해 질문에 답하고, 모든 미션을 완료하면 공연장과 결과 티켓을 확인하는 구조다.

이 폴더는 이후 비주얼·에셋·사용자 경험을 개선하기 전의 기준점을 보존하기 위한 기록이다.

## 2. 전체 진행 흐름

1. 비밀 초대장 도착
2. 초대장을 열고 미션 브리핑 확인
3. 종이비행기를 타고 아지트로 이동
4. 리라즈 아지트에서 입장 가능한 방 선택
5. 캐릭터의 첫 대사 확인
6. 질문에 답하거나 아이디어 입력
7. 미션 완료 보상 획득
8. 다음 방 해금
9. 여섯 미션 완료 후 최종 공연장 진입
10. 완료 티켓에서 선택과 아이디어 확인

## 4. 구현된 기능

- 모바일 세로 화면 우선 레이아웃
- 초대장, 브리핑, 로딩, 홈, 캐릭터 방, 보상, 공연장, 티켓의 상태 기반 화면 전환
- 6개 미션의 순차 해금
- 객관식 답변과 최대 300자의 주관식 아이디어 입력
- 답변의 서버 데이터베이스 저장
- 브라우저 로컬 저장소를 이용한 기기별 진행 상태 복원
- 완료 미션 수에 따른 응원봉 충전 표시
- 완료 티켓에 사용자가 남긴 답변 목록 표시
- 움직임 감소 설정 대응

## 6. 1차 버전의 디자인 특징

- Galmuri 기반 한글 픽셀 타이포
- 네이비 외곽선, 블루·핑크·옐로 계열의 제한 팔레트
- 계단형 모서리와 단단한 픽셀 그림자
- 방 배경과 캐릭터를 분리한 레이어 구조
- 문자 기호와 CSS 도형으로 만든 임시 아이콘 및 장식
- 모바일에서는 게임기 프레임을 제거하고 화면 전체를 사용

## 7. 다음 개선 단계에서 확인할 부분

- 화면별 장식 밀도와 정보 위계 통일
- 임시 문자 아이콘을 일관된 픽셀 아이콘 에셋으로 교체
- 방, 캐릭터, 초대장, 보상 아이템의 픽셀 해상도 및 광원 통일
- 작은 본문과 보조 텍스트의 가독성 향상
- 화면 전환과 선택 피드백의 완성도 향상
- 최종 공연장과 완료 티켓의 소장 가치 강화
- 반복되는 스타일과 화면 컴포넌트 구조 정리
