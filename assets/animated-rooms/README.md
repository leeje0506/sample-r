# Animated room assets

웹 애니메이션과 이후 게임 프로토타입에서 다시 사용할 수 있도록 레이어별로 분리한 원본 에셋입니다.

- `backgrounds/`: 캐릭터를 제거하고 가려진 공간을 복원한 정적 방 배경 6장
- `characters/`: 투명 알파 배경의 독립 캐릭터 6장
- `characters/posed/`: 최초 방 이미지의 포즈와 들고 있던 소품을 그대로 유지한 애니메이션용 캐릭터 6장
- `source/`: 최초 컨셉 이미지와 캐릭터 합본 원본

웹에서의 빛, 반짝임, 바닥 파동은 확대해도 깨지지 않도록 CSS 효과 레이어로 구현했습니다. 실제 조합 결과는 `animated-rooms/` 프로젝트에서 확인할 수 있습니다.
